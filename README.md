# L6_L7_11 — Amusement Park Ride Access

## About

A Python-based amusement park ride access management system that handles ride ticketing and admission based on rider height, age brackets, and medical restrictions. It also monitors safety restraint latch sensors to ensure ride safety.

This repository contains the implementations and testing activities carried out for Lab 6 and Lab 7.

## Lab 6 – Code and Branch Coverage

Focuses on evaluating the effectiveness of test cases using code coverage and branch coverage techniques.

- Unit testing using pytest.
- Measuring code coverage.
- Measuring branch coverage.
- Generating and analyzing coverage reports.

## Lab 7 – Property-Based Testing and Fuzz Testing

Focuses on validating the ride access system using property-based testing and fuzz testing.

- Implementation of ride access validation.
- Property-based testing using Hypothesis.
- Automated random input generation.
- Testing edge cases and invalid inputs.
- Identifying potential failures through fuzz testing.
- Generating the experiment report.
